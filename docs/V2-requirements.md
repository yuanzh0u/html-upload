# html-upload V2 需求文档（技能端）

- 版本：v1.1
- 日期：2026-11-03（v1.0 于 2026-10-22）
- 归属：**技能端**（html-upload），消费服务端能力，不定义接口
- 依赖契约：`docs-api v2.0`（草案 2），见 `html-platform/docs-service/docs/api/v2/contract.md`
- 冲突处理：本文件与契约冲突时**以契约为准**；技能不得自行扩展接口语义。
- 服务端需求见 `docs-service/docs/V2-requirements.md` v1.2

---

## 1. 定位

html-upload 是 Agent 侧的上传与文档维护技能，**可服务多端**（Claude Code、OpenClaw、Cursor 等）。
它把“把一份 HTML 交给平台、按用户意图分享、把链接交回用户”变成标准动作。

边界：技能只负责本机侧的动作；平台能力、授权、存储全部在服务端。

## 2. 技能侧需求

### C-FR-01 契约版本协商 `[对应 FR-08]`

- 每次会话开始先 `GET /api/v2/me`，校验 `api_version` 主版本为 `2`。
- 不兼容时停止并明确告知，不做降级尝试。
- 验收：伪造不兼容 `api_version` 时技能拒绝继续，且不发起任何写请求。

### C-FR-02 撰写摘要 `[对应 FR-07]`

- 上传或替换前，由 Agent 根据 HTML 内容撰写摘要：纯文本，说明这份文档讲什么、结论或用途是什么，**目标 100–300 字，硬上限 1000 字**。
- 不得照抄页面开头的导航、标题、目录或样板文字；不得写入 Key、手机号等敏感信息。
- 本地先校验摘要非空且 ≤1000 字，不合格不发请求。
- 用户提供了摘要时优先使用用户的版本。
- 验收：对 3 份不同类型的 HTML 生成的摘要均为纯文本、≤1000 字、能概括主题；空摘要或超长摘要在本地被拦截，未发出请求。

### C-FR-03 上传 `[对应 FR-07]`

- 只接受本地单个 HTML 文件；上传前本地校验：≤2 MB、UTF-8、计算 `sha256`。
- 每次上传生成 `Idempotency-Key` 并在重试时复用；内容或参数变化则新生成。
- 只发送契约允许字段，不发送 `owner`、上传时间、到期时间、收藏等服务端权威字段。
- 用户指定了分享对象时填入 `share_with`（好友姓名 / 本人群组名）。
- 成功后**必须把返回的 `url` 交给用户**，并说明“对方需登录且在分享范围内才能打开”。
- 成功后本地留 manifest 记录（文档 ID、url、sha256、时间），不含 Key。
- 验收：重复执行同一上传不产生第二条文档；上传成功后用户拿到链接；超 2 MB 或非 UTF-8 文件在本地被拦截。

### C-FR-04 分享结果告知 `[对应 FR-07/09]`

- 读取响应中的 `share_report`；`failed` 非空时**必须逐项明确告诉用户**谁没分享成功及原因（不是好友 / 没有这个群），并提示到网页补分享。
- 不得把部分成功说成全部成功。
- 验收：名单含无效项时，技能输出列出全部失败项与原因；全部成功时如实说明。

### C-FR-05 替换正文 `[对应 FR-18]`

- 用户要更新已上传的文档时，用 `PUT /documents/{id}/content` 替换，不另传新文档；摘要按 C-FR-02 重新确认。
- 可附带 `share_with` 追加分享对象；告知用户“替换只会新增分享，不会移除已有分享”。
- 替换后告知用户：链接不变，到期时间已重新起算。
- 验收：替换后文档 ID 与链接不变；附带名单时只新增分享。

### C-FR-06 文档维护 `[对应 FR-08/13/18]`

- 支持：分页拉取本人文档元数据、按标签/关键词/时间筛选、改标题/摘要/标签、收藏/取消收藏、删除本人文档。
- 删除前向用户确认一次；收藏状态变化如实告知（取消收藏后有 24 小时宽限）。
- 技能不得自行编造标签或替用户决定删除；不确定时向用户确认。
- 仅元数据，不请求或存储正文。
- 验收：1000 条数据分页完整无重复无遗漏；删除未经用户确认时不执行。

### C-FR-07 Key 处理 `[对应 FR-06]`

- Key 只从本地受控文件或环境读取，不进入 argv、URL、日志、报告、manifest。
- 不打印前后缀或片段；引导用户到平台 Key 页面获取与重新生成。
- Key 失效（401）时提示用户重新获取或重新生成，不自动重试。
- 验收：Key 出现在任何输出中即视为失败；401 时零自动重试。

### C-FR-08 错误处理 `[对应契约 §5]`

- 按契约错误码给出可操作的提示：`summary_required`/`summary_too_long` 修正摘要；`file_too_large`/`not_utf8` 修正文件；`daily_limit_reached` 告知次日恢复并遵守 `Retry-After`，不自动重试；`storage_low` 告知平台存储不足、请联系管理员；`not_found` 视为不存在或无权限，不推测；`idempotency_conflict` 生成新 Key 前先确认是否为新内容。
- 不向用户暴露 `request_id` 之外的服务端内部信息。
- 验收：构造各类错误时提示与上述一致，且无敏感信息回显。

## 3. 不做

- 网页端上传入口。
- 上传 / 替换以外的分享操作；撤销分享；好友、群组管理（只在网页）。
- 正文读取或渲染。
- Key 生成（只在页面操作）。
- MCP 接入（V3 再定）。

## 4. 演进约束（多端复用）

- 技能行为不得依赖服务端部署位置、内网地址或特定模型。
- 平台地址、Key 通过配置注入；同一技能应能被不同 Agent 复用。
